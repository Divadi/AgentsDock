伺服器參考

進階安裝與設定

安裝和設定 AgentsServer 的完整參考。日常指令（更新、token、重新啟動、日誌）見管理伺服器；首次架設的分步教程見安裝與連線。

適用於 AgentsServer 1.0.x 釋出版本。權威來源：AgentsServer 原始碼樹、agentsdock --help 和已安裝的原生輔助指令碼。

要求

  • 主機：Linux，或 Apple 晶片的 macOS。不支援 Intel macOS；安裝指令碼會在做任何更改前停止。
  • Node.js/npm：用於 agentsdock CLI。需要 Node.js 22.14 或更高版本。
  • 伺服器的 PATH 中已安裝 uv，並在 npm 安裝前用 uv --version 驗證。它管理隔離的 Python 環境和相依套件，用戶端不需要它。macOS 已安裝 Homebrew 時，用 brew install uv；Linux 或其他方式請見 uv 官方安裝指南。AgentsDock 不會自動安裝 uv，檢查失敗時請看疑難排解。
  • 你計畫使用的服務供應商 CLI（Claude Code、Codex、OpenCode 或 Cursor）已在主機上安裝並登入，且與執行伺服器的是同一個使用者帳號。
  • tmux（可選）——啟用應用程式內終端機、即時窗格檢視和應用程式內託管更新。裝有 Homebrew 的 macOS 上，安裝指令碼會詢問是否代為安裝；否則顯示安裝指令並繼續。
  • Tailscale（可選）——讓其他裝置無需暴露連接埠即可存取伺服器。
  • 可用的使用者層級服務工作階段：launchctl（macOS）或 systemctl --user（Linux）。全程不使用 sudo。

CLI 安裝選項

# 標準預設 setup
npm install -g agentsdock

# 自訂 setup
AGENTSDOCK_SKIP_SETUP=1 npm install -g agentsdock
agentsdock setup [--port PORT] [--bind IP] [--non-interactive] [--dry-run]
  • --port PORT——固定使用指定連接埠。未指定時預設為 7850。
  • --bind ADDRESS——監聽地址。預設 0.0.0.0（所有網路介面，其他裝置可連線）。
  • --non-interactive——從不提示（跳過 tmux 安裝詢問和剪貼簿複製）。用於指令碼和透過 SSH 驅動的執行。
  • --dry-run——顯示實際會執行的原生安裝指令，但不執行。

全域安裝只會在沒有既有安裝或狀態時建立新的預設使用者級服務，標準安裝不需要 clone repo。已有伺服器會保持不變；請從應用程式的設定 → 更新裡更新。單獨在專案裡執行 npm install agentsdock 只會新增依賴，不會建立服務。執行中的服務也不會從 npm cache 中執行。

安裝完成後，檢視 token 用 agentsdock token，解除安裝預設伺服器用 agentsdock remove default，命名執行個體用 agentsdock new / agentsdock list。原生輔助指令碼仍位於 ~/.local/share/agents-server/current，供進階疑難排解使用。

連接埠與繫結地址

如果預設連接埠已被某個不是待替換 AgentsServer 的處理程序佔用，安裝指令碼會報告該監聽處理程序（可用時藉助 lsof），並在向上最多五個空閒連接埠中選一個。所選連接埠會在執行結束時顯示。

  • --port 會固定該連接埠，被佔用時直接失敗。

繫結到 0.0.0.0（預設）以接受其他裝置的連線；只有應用程式與伺服器在同一臺機器上時才繫結 127.0.0.1。繫結到迴環地址的伺服器無法透過 Tailscale 存取。

遠端存取（Tailscale）

遠端存取推薦走 Tailscale，這樣手機、平板和筆記型電腦都能存取伺服器，而無需把連接埠釋出到網際網路。它是可選的；主機上沒有 Tailscale 時，安裝指令碼只會顯示一條提醒。

在伺服器上：

tailscale status
tailscale ip -4

在每臺裝置上加入同一個 tailnet，然後使用伺服器 URL：

http://<tailscale-ip>:7850

如果裝置上的瀏覽器能開啟 /api/health 但應用程式連不上，請檢查：裝置已連線 Tailscale、URL 帶有連接埠、應用程式裡填的是同一個 token，以及伺服器繫結的是 0.0.0.0（而不只是 127.0.0.1）。

切勿把 7850 連接埠暴露到公網。使用 Tailscale 或其他私有網路，並保持 token 啟用。

token

安裝指令碼會產生一個私有的 bearer token。每個 HTTP 呼叫、上傳、檔案/影片獲取和 WebSocket 流都需要它。隨時可以這樣取回：

agentsdock token

用戶端以 Authorization: Bearer <token>（或 X-AgentsDock-Token 請求頭）傳送它。如需在伺服器機器上做低層健康檢查：

curl -H 'Authorization: Bearer YOUR_TOKEN' http://127.0.0.1:7850/api/health

服務範本

安裝指令碼會為你建立並管理使用者服務：macOS 上是 LaunchAgent com.agentsdock.server，Linux 上是 agents-server.service。只有自訂部署才需要下面的範本。

mkdir -p ~/.config/systemd/user
cp systemd/agents-server.service.example ~/.config/systemd/user/agents-server.service
systemctl --user daemon-reload
systemctl --user enable --now agents-server.service
systemctl --user status agents-server.service --no-pager -l

兩個平臺的啟動、停止、重新啟動和日誌指令見管理伺服器。

環境變數

大多數設定都是伺服器讀取的環境變數。新設定請使用 AGENTSDOCK_* 名稱；歷史上的 ZENITHBOT_* / ZENITHDOCK_AGENT_TOKEN 僅作為相容別名接受。括號內為預設值。

網路與存取

  • AGENTSDOCK_AGENT_BIND——繫結地址（0.0.0.0）
  • AGENTSDOCK_AGENT_PORT——連接埠（7850）
  • AGENTSDOCK_AGENT_TOKEN——共享的 bearer token（未設定）

路徑

  • AGENTSDOCK_STATE_DIR——對話、工作和檔案狀態（~/.agentsdock）
  • AGENTSDOCK_AGENT_CWD——新對話的預設工作目錄（你的主目錄）
  • AGENTS_SERVER_INSTALL_DIR——版本化執行環境根目錄（~/.local/share/agents-server）
  • CLAUDE_PROJECTS_ROOT——Claude 歷史搜尋根目錄（~/.claude/projects）
  • CODEX_SESSIONS_ROOT——Codex 歷史搜尋根目錄（~/.codex/sessions）

後端

  • AGENTSDOCK_BACKEND——預設後端，claude 或 codex（claude）
  • CLAUDE_BIN / CODEX_BIN——可執行檔案名或路徑（claude / codex）
  • AGENTSDOCK_CLAUDE_TRANSPORT——互動式 Claude 傳輸方式：auto、agent-sdk 或 print（auto）
  • AGENTSDOCK_CLAUDE_SDK_IDLE_TTL_SECONDS——每個對話的 SDK 用戶端空閒保留時間（300）
  • AGENTSDOCK_CLAUDE_SDK_MAX_LOADED_CHATS——最多保留的對話 SDK 用戶端數（4）
  • AGENTSDOCK_RUNTIME_CATALOG_TIMEOUT_SECONDS——每條指令的 CLI 版本/幫助/模型探測超時（6）
  • AGENTSDOCK_CLAUDE_AUTH_PROBE_TIMEOUT_SECONDS——claude auth status 的超時（15）
  • AGENTSDOCK_RUNTIME_DIAGNOSTIC_TTL_SECONDS——CLI 版本/登入探測結果的快取時長（60）

工作與保護

  • AGENTSDOCK_JOB_MAX_ACTIVE_RUNS——排程工作並行上限；0 表示不限（0）
  • AGENTSDOCK_MAX_ACTIVE_AGENT_RUNS——對話、排程和目標執行的全伺服器上限；0 = 不限（0）
  • AGENTSDOCK_JOB_MIN_AVAILABLE_MEM_MB——工作啟動的記憶體保護閾值（4096）
  • AGENTSDOCK_MIN_START_AVAILABLE_MEM_MB——互動式啟動的記憶體保護閾值（2048）
  • AGENTSDOCK_CODE_DIFF_SNAPSHOT_TIMEOUT_SECONDS——每次隔離 Git worktree 快照的最長時間（120）

上下文摘要

  • AGENTSDOCK_HANDOFF_DIGEST_BACKEND——claude 或 codex（claude）
  • AGENTSDOCK_HANDOFF_DIGEST_MODEL——模型（sonnet）
  • AGENTSDOCK_HANDOFF_DIGEST_EFFORT——可選的推理/努力程度設定（未設定）
  • AGENTSDOCK_HANDOFF_DIGEST_TIMEOUT_SECONDS——摘要產生超時（180）
  • AGENTSDOCK_HANDOFF_DIGEST_CHARS——最終摘要的字元上限（56000）

檔案位置

  • ~/.agentsdock——狀態：對話、工作、檔案、上傳、token、安全對等憑據
  • ~/.config/agents-server/env——產生的服務設定和 token
  • ~/.local/share/agents-server/releases/<version>——版本化的釋出；~/.local/share/agents-server/current 指向目前生效的版本
  • ~/Library/Logs/AgentsServer/（macOS）· journalctl --user -u agents-server.service（Linux）——日誌

命名執行個體使用各自的同級路徑——見每個執行個體的位置。
