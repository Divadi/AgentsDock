功能指南 / 對話

Agent 之間通話

用 @ 把另一個 agent 拉進對話並交給它一個工作——它在自己那邊完成後回覆你。

開始一段 agent 之間的通話

輸入 @，選擇你要聯絡的對話，然後傳送。提及標籤會標明你在對誰說話——它跨對話有效，甚至跨伺服器也可以。

工作原理

你的訊息會作為一次可追蹤的訊息交換送達。對方 agent 在它自己的機器上處理，然後直接回復到你的對話裡，整個交接過程清晰可見——發給了誰、是否等待回覆、何時過期。

第一條訊息同時會建立一條持久連線：在 @ 選擇器裡，該對話會從傳送後將授予 Send + Ask變為已授予 · Send + Ask，之後你可以持續給這個 agent 發訊息，無需再次授權。

撤銷存取

開啟 @ 選擇器，點選已連線對話旁的撤銷（Revoke）。這會關閉連線，直到你再次 @ 它。每個對話能保持的連線數有限，請撤銷不再需要的連線。
