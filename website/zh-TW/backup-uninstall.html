伺服器參考

備份、恢復與解除安裝

AgentsServer 把所有東西都以普通目錄的形式存放在你的機器上。本頁說明各項內容的位置、如何備份和恢復，以及解除安裝時到底刪除什麼、保留什麼。

適用於 AgentsServer 1.0.x。命名執行個體路徑和名稱釋放備份需要多伺服器中描述的 main 分支構建。

什麼存在哪裡

  • 狀態——對話及其事件歷史、排程工作、上傳和產生的檔案、安全對等憑據、終端機中繼資料：~/.agentsdock（預設伺服器）· ~/.agentsdock-instances/NAME（命名執行個體）
  • 設定——token 和服務設定：~/.config/agents-server · ~/.config/agents-server-instances/NAME
  • 執行環境——已安裝的釋出版本及其 Python 環境（完全可重灌，不含個人資料）：~/.local/share/agents-server · ~/.local/share/agents-server-instances/NAME
  • 日誌——~/Library/Logs/AgentsServer/（macOS）或使用者日誌（Linux）

你的 Claude Code 和 Codex 對話本身存放在這些工具自己的目錄裡（~/.claude、~/.codex），專案檔案則在你自己存放的位置——AgentsServer 只引用它們，並不擁有它們。

備份

只有狀態和設定目錄重要；執行環境可以重灌。先停止伺服器，避免複製過程中檔案發生變化：

# macOS
launchctl bootout gui/$(id -u)/com.agentsdock.server
# Linux
systemctl --user stop agents-server.service

cp -a ~/.agentsdock ~/agentsdock-backup-$(date +%F)
cp -a ~/.config/agents-server ~/agentsdock-config-backup-$(date +%F)

# then start it again
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.agentsdock.server.plist   # macOS
systemctl --user start agents-server.service                                           # Linux

對於命名執行個體，請使用它自己的服務名和每個執行個體的位置中列出的 …-instances/NAME 路徑。設定備份包含你的 token——請存放在私密的地方。

恢復

原位狀態會被自動接管。如果狀態目錄還在（正常解除安裝後就是如此），重新安裝會連上同樣的對話、工作和檔案。除非設定目錄也保留了，否則重灌會產生新的 token——若是這樣，請在應用程式裡更新 token。

從你自己做的備份恢復：停止伺服器，把備份的目錄放回原來的路徑，再啟動它（或執行 npm install -g agentsdock）。想保留舊 token 的話，把設定目錄也一併恢復。

重灌不會自動恢復名稱釋放備份——那部分在下文單獨說明。

解除安裝

agentsdock remove default                 # default server
agentsdock remove work                    # one named instance
agentsdock remove --all                   # everything
agentsdock remove --all --exclude default # all named instances, keep default
agentsdock remove default --yes           # skip the prompt

解除安裝會移除使用者服務、版本化的執行環境，以及包括 token 在內的產生設定。它會保留狀態目錄下的對話歷史、工作、檔案、安全對等憑據和終端機，之後重新安裝會接管同樣的歷史。它從不使用 sudo，並拒絕對根目錄、主目錄、寬泛的系統目錄或相互重疊的路徑進行操作。

名稱釋放備份

當一個命名執行個體的名稱被釋放時（移除它，或用同一名稱建立新執行個體），它的狀態目錄不會被刪除——而是移到一個私有備份：

~/.config/agents-server-manager/history-backups/<name>-<random>/state

預設執行個體的名稱永遠不會被釋放。原始的 Claude/Codex 對話和你的專案檔案不受影響；只有 AgentsDock 自有的內容會移入備份。

釋放名稱會把它儲存的 AgentsDock 資料保留在指令顯示的私有備份位置。重灌該執行個體不會自動恢復那個備份，重灌後的執行個體從空的對話清單開始。目前還沒有內建的恢復指令——請保持備份原樣（不要移動或合併它，尤其是在該名稱已被重新使用的情況下），並到 Discord 或透過回報問題尋求恢復指引。

清除狀態

agentsdock remove default --purge-state

這是唯一的破壞性選項。它會永久刪除狀態目錄——對話歷史、工作、檔案、token、安全對等憑據。它總是要求你輸入完整的狀態路徑確認，--yes 永遠無法跳過這個提示。

終端機對話

解除安裝後，持久對話終端機仍會繼續執行。它們是普通的 tmux 對話，按伺服器隔離：

tmux ls                          # default server: sessions named zd_*
tmux -L agents-server-NAME ls    # named instance: sessions named zdi_NAME_*

只關閉你確認屬於所移除伺服器的 AgentsDock 對話終端機。機器上的其他 tmux 對話以及其他執行個體的對話是獨立的，不受影響。
