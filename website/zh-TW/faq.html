常見問題

關於 AgentsDock 的常見問題，點選問題展開答案。沒找到？告訴我們，我們會補充到這裡。

為什麼在 AgentsDock 裡看不到最新的 Codex 或 Claude 模型？

AgentsDock 連線的是執行 AgentsServer 那臺機器上的 agent runtime。應用程式裡的模型清單來自那臺機器上的 Codex 和 Claude Code CLI，所以更新手機或電腦上的 AgentsDock 應用程式並不會帶來新模型。

如何獲取最新模型

  1. 在執行 AgentsServer 的那臺機器上（不是你正在用來連線的裝置）更新對應的 provider CLI： 
    # Codex
codex update
codex --version

# Claude Code
claude update
claude --version
  2. 回到 AgentsDock，開啟設定（Settings），點選 Recheck CLIs 重新整理模型清單。不需要重新啟動伺服器。
  3. 還是沒有？先確認你連線的是剛更新的伺服器，再檢查 provider 的帳號或訂閱方案、工作區管理員設定，以及該模型是否已開放給你使用。更新 CLI 可以更新模型清單，但不會改變帳號的使用權限。

如果你有多臺伺服器，每臺都要更新一次——每臺伺服器有自己獨立的 CLI。

AgentsDock 支援哪些平臺？

用戶端支援 macOS、Windows、Linux、iPhone、iPad 和 Android。伺服器端 AgentsServer 執行在 macOS（Apple 晶片）或 Linux 上。各平臺的安裝方法見用戶端安裝。

AgentsDock 會看到我的程式碼、提示詞或模型請求嗎？

不會。AgentsDock 在你自己的機器上執行 Claude Code、Codex、OpenCode 和 Cursor 等 provider CLI，從不代理你的模型請求。匿名使用統計預設關閉，可在設定中開啟。詳情見隱私政策。

我需要 Tailscale 嗎？

只有在區域網路之外存取伺服器時才需要。在同一 Wi-Fi 下可以直接用機器的區域網路 IP。Tailscale 會給伺服器分配一個私有的 100.x.x.x 地址，無需開放連接埠就能從任何地方存取。見安裝與連線。

可以連線多臺伺服器嗎？

可以。在側邊欄頂部的伺服器選單裡用 Add Server 逐個新增，之後隨時切換。每臺伺服器保留自己的對話。

伺服器機器重新啟動後，需要手動重新啟動 AgentsServer 嗎？

通常不需要。安裝程式會把 AgentsServer 註冊成使用者級服務，所以對應的服務對話恢復後它會自動啟動。macOS 上是在伺服器使用者登入時啟動；Linux 上的 user systemd 服務會被啟用到預設 target。

機器重新上線後，直接開啟 AgentsDock 重新連線即可。如果沒有自動恢復，可以到管理伺服器檢視服務狀態。

token 在哪裡找？

在伺服器機器上執行：

agentsdock token

在應用程式裡新增伺服器時，把它貼上到token（Access token）一欄。

可以恢復在 AgentsDock 之外開始的對話嗎？

可以。從 / 選單開啟匯入對話（Import chat），從那臺機器上所有的 Claude Code 或 Codex 對話裡挑選；或者選擇按對話 ID 恢復（Resume by session ID）並貼上 ID。兩種方式都會帶上完整歷史。見恢復其他對話。

怎麼更新 AgentsDock 和伺服器？

兩者都在應用程式的設定裡更新：點 Check now；應用程式更新用 Restart to update，伺服器提示出現時用 Update server 或 Retry server update。見更新。

AgentsDock 開源嗎？

開源。AgentsDock 現在統一放在我們的 GitHub repo。歡迎點個 star。
