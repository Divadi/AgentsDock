功能指南

每個功能都有自己的頁面；這裡按工作方式分組，方便你先選方向，再進入具體操作。

對話

對話與協作

把對話本身當作協作入口：交給另一個 agent 處理、分享給其他人、從目前上下文開一個分支，或用 Side chat 問一個不打斷主線的小問題。

01 Agent 之間通話 用 @ 把另一個對話拉進來，讓另一個 agent 接手一段工作。 02 用連結和 token 分享對話 產生受保護的瀏覽器頁面，要求 token 存取，並且可以隨時撤銷。 03 Side chat 側聊 圍繞目前上下文快速追問，但不打斷主對話。 04 Fork 任意對話 把完整歷史複製到一個新分支，用來嘗試另一條路線。 05 恢復其他對話 匯入或恢復在 AgentsDock 之外開始的 Claude Code / Codex 對話。

工作區

在遠端機器上工作

真正的工作發生在你的伺服器上；桌面和行動版用戶端只是視窗，讓你從任何裝置存取終端機、檔案和工作目錄設定。

06 從任何裝置完整存取終端機 在桌面、iPhone、iPad 或其他用戶端開啟同一個持久 shell。 07 檢視與編輯你的程式碼 在應用程式裡瀏覽和編輯目前對話工作目錄下的檔案。

自動化

更快操作，並安排之後的工作

在對話中用快捷指令快速執行操作；需要稍後執行的事情，則交給排程工作，即使不一直開著應用程式也能繼續。

08 斜線指令 用一個快速選單開啟附件、引用對話、回報、切換模型等操作。 09 排程工作 把之後要做或需要重複執行的工作交給伺服器執行。
