開始第一個對話

伺服器架設並連線好之後，和 agent 開始一段對話只需一次點選。

首先，確認已連線

開啟 AgentsDock，在伺服器切換器裡檢視你的伺服器。綠點表示伺服器線上且已連線；紅點表示應用程式無法存取它。

連線伺服器需要兩樣東西：它的地址——伺服器的 IP 或主機名稱加連接埠 7850——以及它的token。在應用程式裡填好後，點選測試連線（Test connection）。

還沒架設伺服器？安裝與連線會一步步帶你把伺服器跑起來、找到它的地址和 token，再連線你的裝置。

開始對話

點選側邊欄頂部的 + 按鈕——即新建對話（New chat）——或按 ⌘N。

傳送第一條訊息前，檢查兩件事：

  • 工作目錄——AgentsDock 會預設沿用上一個對話的資料夾；如果這次要在別的專案裡工作，可以改成遠端機器上的其他目錄。
  • agent provider——用左下角的切換器，在這臺伺服器可用的 Claude Code、Codex、OpenCode、Cursor 等 provider 之間切換。

然後輸入第一條訊息，按 Enter 傳送。就這麼簡單——agent 在你伺服器上的那個目錄裡執行，而這個對話擁有自己的持久終端機，你隨時可以從任何裝置接入。如果還需要先連線另一個 provider，可以看連線 agents。
