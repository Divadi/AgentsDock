用戶端安裝

在支援的裝置上安裝 AgentsDock 用戶端，然後連線到你的 AgentsServer。用戶端是進入伺服器的視窗；對話和 agent 工作會在你搭好的遠端機器上執行。

1Mac 桌面應用程式

下載 macOS .dmg，開啟後按提示把 AgentsDock 放到 Applications，然後從 Applications 或 Launchpad 開啟。

下載 macOS 版 →

需要 macOS 14 或更高版本。目前桌面版本同時支援 Apple silicon 和 Intel Mac。

2Windows 桌面應用程式

下載 Windows .exe 安裝檔，執行安裝器，安裝完成後開啟 AgentsDock。

下載 Windows 版 →

需要 Windows 10 或更高版本，x64 架構。目前 Windows 安裝檔未簽章。

3Linux 桌面應用程式

根據機器選擇 x86_64 或 ARM64 的 AppImage。下載後如果系統沒有自動賦予執行權限，可以先執行下面的指令，再雙擊或從命令列啟動。

chmod +x AgentsDock-*.AppImage
./AgentsDock-*.AppImage

下載 Linux x86_64 → 下載 Linux ARM64 →

大多數 Intel/AMD 電腦選擇 x86_64；ARM Linux 機器選擇 ARM64。

4iPhone 和 iPad

在你的 iPhone 或 iPad 上，從 App Store 下載 AgentsDock 並開啟。

在 App Store 下載 AgentsDock →

需要 iOS / iPadOS 16.4 或更高版本。

5Android

Android 目前透過 APK 分發。開啟 Android release 頁面，下載 APK 資源；如果系統提示，允許從瀏覽器或檔案管理器安裝，然後開啟 AgentsDock。

開啟 Android APK release 頁面 →

目前 Android APK：AgentsDock 0.1.1 beta.7 arm64。釋出頁包含構建資訊、SHA-256 校驗值和驗證說明。

6連線到你的伺服器

安裝用戶端後，新增伺服器地址和存取 token。第一次用？先按安裝與連線把伺服器跑起來，再開始第一個對話。
