回報問題

遇到 bug，或者有功能建議？問題都在 GitHub 上——而最快的入口就在對話裡。

在對話中傳送回報

在輸入框輸入 /feedback——或從 / 選單選擇傳送回報（Send feedback）。它會直接帶你到 GitHub 上的 AgentsDock 問題表單，不用去找儲存庫。

在 GitHub 上開啟 AgentsDock 問題表單 →

……或直接在 GitHub 上提交問題

目的地相同，如果你更願意直接過去的話。在 AgentsDock 儲存庫新建一個 issue，寫清標題和描述——重現步驟、你期望的結果、實際發生了什麼——能附上螢幕截圖或螢幕錄影更好。這對我們定位問題非常有幫助。

在 GitHub 上新建 issue →

建議先快速翻一下已有的 issue——也許已經有人報告過了。

更喜歡 Discord？

有簡短的問題，或者拿不準某個現象算不算 bug？歡迎來社群打個招呼。我們很活躍，樂意幫忙。
