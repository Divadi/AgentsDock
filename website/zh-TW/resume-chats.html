功能指南 / 對話

恢復其他對話

把你在 AgentsDock 之外開始的 Claude Code 或 Codex 對話帶進應用程式，完整保留歷史和上下文。

我們建議你直接匯入。

直接匯入

從 / 選單開啟匯入對話（Import chat），就能看到那臺機器上所有的 Claude Code 和 Codex 對話——每條都帶預覽和時間戳記。勾選想要的對話並點匯入（Import），它們就會帶著完整歷史進入 AgentsDock——包括完全在應用程式之外進行的對話。

使用 Resume ID 匯入

每個 Claude Code 或 Codex 對話都有一個對話 ID——也就是它的 Resume ID。選擇按對話 ID 恢復（Resume by session ID），貼上 ID，AgentsDock 就會在應用程式裡恢復那段對話，完整保留歷史和上下文，讓你能從任何裝置接著聊。它適用於你在 AgentsDock 之外開始的對話，而不只是應用程式內新建的。
