功能指南 / 對話

用連結和 token 分享對話

建立受保護的瀏覽器分享：唯讀分享用於檢視儲存的對話紀錄，Interactive 分享適合讓信任的人進入同一個即時對話一起操作。

在對話選單中選擇 Share Chat，再選擇 View only 或 Interactive。之後把產生的連結和 access token 發給對方即可。下面這段示範已經隱藏真實的分享地址和 token。

開啟分享頁面

對方開啟分享連結後，需要輸入你提供的 access token。也可以把 token 記在目前瀏覽器裡；存取權限會一直保留到分享過期，或你手動撤銷。

隨時撤銷

已建立的分享會列在原對話的分享視窗中。再次開啟 Share Chat，點選 Revoke 即可撤銷存取權限，讓連結立即失效。

在瀏覽器裡一起協作

View only 分享會開啟一份已儲存的對話。Interactive 分享會開啟即時共享對話，信任的人可以在瀏覽器裡繼續發訊息、附加圖片，並接著同一個對話工作。
