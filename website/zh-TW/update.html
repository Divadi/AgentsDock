更新到最新版本

AgentsDock 在應用程式設定裡就地更新。你可以透過兩個管道選擇接收新版本的方式：穩定版（Stable）和測試版（Beta）。

如何在應用程式內更新到最新版本

開啟設定並捲動到更新區域。AgentsDock 會檢查新版本並顯示可用的更新——點選立即檢查（Check now），再點重新啟動以更新（Restart to update），即可安裝並以最新版本重新啟動。

應用程式和伺服器一起更新

AgentsDock 由兩部分組成——應用程式（你裝置上的用戶端）和 AgentsServer（執行在你的遠端機器上）。兩者在同一面板裡各自顯示版本編號，各有自己的檢查和更新控制元件。

更新時，請把兩端同時升到最新版本。應用程式和伺服器保持版本一致可以避免不匹配——功能和修復往往兩邊一起釋出。在設定 → 更新裡點選 Check now；應用程式更新用 Restart to update，遠端伺服器在出現提示時用 Update server 或 Retry server update。

穩定版與測試版

應用程式和伺服器都有穩定版（Stable）/測試版（Beta）開關：

  • 穩定版——打磨完善、充分測試的釋出版本。日常使用的正確選擇。
  • 測試版——最新的簽章構建，功能和修復會先於穩定版到達。適合想搶先體驗、不介意偶爾有小毛病的人。

兩端選擇同一管道，讓應用程式和伺服器步調一致。想知道每個版本具體改了什麼、哪些是穩定版哪些是測試版？所有釋出版本及其說明都在 GitHub 上。
